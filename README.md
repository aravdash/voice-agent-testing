# Clinic Voice Assistant Demo

A web-based demo of our AI-powered clinic voice assistant.

## Features
- 🎤 Voice input and output
- 🤖 AI-powered responses using GPT-4o
- 🗣️ Custom trained voice synthesis
- 📅 Appointment scheduling assistance

## Live Demo
[Access the demo here](https://your-app-name.streamlit.app) *(Link will be available after deployment)*

## How it works
1. Click the microphone button
2. Speak your question or request
3. Get an AI-generated response
4. Listen to the synthesized voice reply

## Technology Stack
- **Frontend**: Streamlit web app
- **Voice Recognition**: Faster-Whisper
- **AI Responses**: OpenAI GPT-4o
- **Voice Synthesis**: Custom Orpheus model
- **Audio Processing**: SNAC codec

## For Developers
This demo connects to a RunPod-hosted TTS server for voice synthesis. The server uses a custom-trained Orpheus model for natural-sounding clinic assistant responses.
